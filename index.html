Footy Pool 2026

Founder & Solo Developer · Live

A free-to-play World Cup prediction game with an AI football pundit. I designed and built the full-stack app from scratch in Next.js 16 (App Router, Turbopack), React 19 and TypeScript, deployed on Vercel with a push-to-deploy workflow. Players predict matches, climb a live leaderboard, and get personality-driven roasts of their picks from "Rano," an AI pundit I built.

  • Architected "Rano," an AI pundit that generates shareable, persona-driven roasts — designing the prompt system and brand voice.
  • Built a pari-mutuel (pool-based) token model with randomized per-match metrics for a virtual-currency prediction market — no real-money betting.
  • Responsive, component-driven UI in Tailwind CSS v4 (custom design tokens): prediction interface, rankings, pools, profiles, and an early-access landing page with email capture.
  • Created the full brand system end to end — logo, prism gradient identity, typography, and marketing assets.

002

MindSpace

AI Mental-Health Chatbot · Solo project PRIVATE REPO

A supportive chatbot that reads how someone is feeling and replies safely. It classifies the intent behind each message with a TF-IDF + neural-network model (~93% test accuracy), then routes by confidence: a confident guess gets an empathetic reply learned from real counseling data, while an unsure one retrieves an authentic passage from official WHO guidelines.

  • Full data-science pipeline: EDA, cleaning, NLP preprocessing, train/test evaluation.
  • RAG-style retrieval over 554 WHO passages using sentence embeddings + FAISS.
  • Tone-correction and anti-repetition guardrails for natural conversation.
